# International_Debt_Analysis
An end-to-end data analytics project using Bank International Debt Statistics data. Python was used for data cleaning, preprocessing, and exploratory data analysis (EDA). MySQL was used to create a relational database, manage datasets, and perform SQL JOIN operations. Power BI was used to develop an interactive dashboard with KPI cards, gauges, charts, and slicers. The dashboard analyses total external debt, debt growth, average debt, country-wise debt, regional distribution, and income group comparisons, providing meaningful insights into global debt patterns and trends.
